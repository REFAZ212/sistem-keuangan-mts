# Security Standard

## Authentication

* Laravel Breeze
* Password Hashing Bcrypt/Argon2

## Authorization

* Spatie Permission

## Database

* Prepared Statement Only
* Eloquent ORM

## Input Validation

* Laravel Form Request

## Logging

* Semua aktivitas penting dicatat.

## Backup

* Backup harian
* Backup mingguan
* Backup bulanan

## Sensitive Data

* Password tidak boleh disimpan dalam plaintext.
* File .env tidak boleh masuk repository.

## Git

* Tidak boleh commit:

  * .env
  * storage/logs
  * vendor
  * node_modules
